# PSCO Glossary

## Product

面向真实用户持续创造价值的软件产品。  
在 `v0.1` 中属于核心实体。

## Module

可独立演化、验证、复用的软件能力单元。  
在 `v0.1` 中属于核心实体。

## Release

模块的一次正式版本演进。  
在 `v0.1` 中属于核心实体。

## Decision

在特定上下文中的关键选择。  
在 `v0.1` 中属于核心实体，并采用低摩擦结构化模板。

## Repository

Product 或 Module 的代码实现载体。  
在 `v0.1` 中先承担手动绑定与实现映射职责。

## Venture

长期探索方向。  
在 `v0.1` 中保留为可选实体。

## Capability

多个模块与实践积累形成的长期能力。  
在 `v0.1` 中为派生结果层，不作为重实体。

## Feature

用户价值到软件能力之间的连接点。  
继续保留在长期模型中，但不进入 `v0.1` 主执行范围。

## Opportunity

值得探索的问题或商业机会。  
继续保留在长期模型中，但不进入 `v0.1` 主执行范围。

## Experiment

用于验证假设的最小行动。  
继续保留在长期模型中，但不进入 `v0.1` 主执行范围。
