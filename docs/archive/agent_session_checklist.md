# Agent Session Checklist

## 1. 接手前

按以下顺序读取：

1. `AGENTS.md`
2. `project_rules.md`
3. `plan.md`
4. `architecture_map.md`
5. `PSCO-summarize-feedback.md`
6. `docs/README.md`

## 2. 开始前确认

1. 当前任务是否属于 `v0.1` 必做范围
2. 当前修改是否会重新引入第二套解释
3. 当前变更是否会制造文档孤岛
4. 当前任务应该走 `phase`、`fix` 还是 `audit`

## 3. 执行中检查

1. 是否已经读取直接上下游文档
2. 是否已经明确影响文件清单
3. 是否存在未冻结但被默认拍板的设计点
4. 是否需要补 `docs/README.md` 或分类目录入口

## 4. 收口时检查

1. 是否与 `PSCO-summarize-feedback.md` 保持一致
2. 是否需要同步更新 `plan.md`
3. 是否需要同步更新 `architecture_map.md`
4. 是否需要同步更新 `docs/README.md`
5. 是否明确标注“已完成 / 未完成 / 后移项”
